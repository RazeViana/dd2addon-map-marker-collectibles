# Third-party notices

Map Markers and Collectables by Raze is an adaptation of **Arisen's Almanac by gibbed**, using the source package supplied for this project. The original map-marker logic and location datasets come from that package. Its existing compatibility changes were supplied with it; their authorship has not been independently established.

- Original script: https://github.com/gibbed/DD2-REFramework-Scripts/blob/main/gibbed_Almanac.lua
- Original mod: https://www.nexusmods.com/dragonsdogma2/mods/194
- Original author: https://gib.me/ and https://github.com/gibbed
- Minimap investigation reference: https://github.com/gibbed/DD2-REFramework-Scripts/blob/main/gibbed_MinimapTest.lua

The original package is preserved in `reference/almanac-source.zip` in the development project. The 12 JSON datasets are preserved byte for byte, including their original author and source metadata. The old preview image is retained only as a development reference.

Raze's version changes the mod identity and file paths, adds nearby minimap rendering with shared category settings, expands both maps' sprite capacity, adds settings migration and validation, improves error handling, and adds a runtime diagnostic exporter. It is a modified version, not the original release. No upstream license file was included in the supplied package; this document does not grant new rights to the original material.
