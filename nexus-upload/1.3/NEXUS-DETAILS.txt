Main file description (250 characters maximum; also in FILE-DESCRIPTION.txt)
Version 1.3 adds separate fog-of-war toggles for chests, Golden Trove Beetles, and Seeker's Tokens on both maps. All default off. Requires REFramework. Install the complete ZIP and restart the game.

Version 1.3 changelog
- Added independent Hide chests in unexplored areas, Hide beetles in unexplored areas, and Hide Seeker's Tokens in unexplored areas toggles for both maps. The chest option covers regular and special chests.
- All three options default off and keep your category and Acquired/Unacquired choices. The chest preference from the earlier chest-only 1.3 package is preserved.
- Minimap visibility updates as fog clears, including with cached locations; hidden collectables do not count toward the marker limit.
- Temporarily unavailable fog data keeps affected markers hidden, with a menu message and automatic recovery.

Update instructions
Close the game, install the complete ZIP, and restart. Keep reframework/data/raze_MapMarkersAndCollectables_settings.json to preserve your settings. Enable the desired fog options for chests, beetles, and Seeker's Tokens in the mod menu. If you downloaded the earlier chest-only 1.3 package, reinstall this updated ZIP; the added beetle and token options start disabled.
