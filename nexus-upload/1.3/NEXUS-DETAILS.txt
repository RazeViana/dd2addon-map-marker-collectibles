Main file description
Version 1.3 adds an optional fog-of-war toggle for regular and special chests on both maps. Off by default. Includes all 1.2 features and fixes. Requires REFramework. Install the complete ZIP and restart the game.

Version 1.3 changelog
- Added Hide chests in unexplored areas for regular and special chests on the full map and minimap.
- The option is off by default and keeps your category and Acquired/Unacquired choices.
- Minimap chest markers update as fog clears; hidden chests do not count toward the marker limit.
- Temporarily unavailable fog data keeps affected chests hidden, with a menu message and automatic recovery.
