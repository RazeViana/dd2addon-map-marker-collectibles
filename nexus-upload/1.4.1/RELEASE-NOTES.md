# Map Markers and Collectables by Raze 1.4.1

- Fix the first Seeker's Token marker disappearing when the Sphinx riddle begins, before the Finder's Token is collected.
- Read the game's saved first-token location and Finder pickup state, including when installing into an existing playthrough. No fresh save is required.
- Add **Show after Finder's Token collection**, disabled by default, to keep the red first-token location visible after collecting or handing in the Finder's Token.
- Save the new preference and refresh it on both maps. The main first-token switch, token fog and map settings, and minimap distance and height limits still apply.

Open **REFramework > Script Generated UI > Map Markers and Collectables by Raze**. Enable **Show first Seeker's Token**, then **Show after Finder's Token collection** to retain the location after collection. Leave the new option off for automatic removal.

Requires [REFramework for Dragon's Dogma 2](https://www.nexusmods.com/dragonsdogma2/mods/8).

Close the game and install the complete ZIP with Fluffy Mod Manager. For manual installation, copy both reframework and natives into the game folder beside DD2.exe, then restart. Keep reframework/data/raze_MapMarkersAndCollectables_settings.json to retain your choices.

This is the full mod package and includes all v1.4 chest data, appearance choices, progression filtering and map fixes.

Source credits and notices are included in `docs/raze_MapMarkersAndCollectables/THIRD_PARTY_NOTICES.md` inside the download.
