Main file description (250 characters maximum; also in FILE-DESCRIPTION.txt)
v1.4.1 fixes the first Seeker's Token marker during the Sphinx riddle and adds an option to keep its location visible after Finder's Token collection. Supports existing saves. Full package; requires REFramework.

Version 1.4.1 changelog
- Fix the first Seeker's Token marker disappearing when the Sphinx riddle begins, before the Finder's Token is collected.
- Read the game's saved first-token location and Finder pickup state, including when installing into an existing playthrough. No fresh save is required.
- Add Show after Finder's Token collection, disabled by default, to keep the red first-token location visible after collecting or handing in the Finder's Token.
- Save the new preference and refresh it on both maps. The main first-token switch, token fog and map settings, and minimap distance and height limits still apply.

Update instructions
Close the game and install the complete ZIP with Fluffy Mod Manager. For manual installation, copy both reframework and natives into the game folder beside DD2.exe, then restart. Keep reframework/data/raze_MapMarkersAndCollectables_settings.json to retain your choices. Show first Seeker's Token starts enabled; Show after Finder's Token collection starts disabled. Enable both to keep the location visible after collection. Existing category, appearance and fog choices are kept.
